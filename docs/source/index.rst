NSA-Flow documentation
======================

**NSA-Flow** is a Python library for Non-negative Stiefel-Approximating Flow: a single, calibration-free relaxation between data reconstruction and feature clustering.

The "Package Reference" highlights commonly used functionality, organized thematically.

See the "API Reference" for the full list of available modules and functions.

More resources:

- `NSA-Flow GitHub <https://github.com/stnava/nsa_flow>`_ for source code, bug reports, and contributions.
- `Paper & Mathematical Foundations <https://github.com/stnava/nsa_flow/tree/main/paper>`_ for theory and propositions.
